## 데이터 파일
- JSON: 스크래치패드 `careers-liberal.json` (전공 키 12개: business, finance, social_sci, prelaw, psychology, humanities, arts, media, cognitive_science, actuarial, public_health, linguistics)
- 각 전공에 `outlook_note_ko`(BLS 전망 표현을 그대로 반영), 대학원 필수 전공에는 `grad_note_ko` 포함
- nursing 계열은 별도 배치에서 담당 (이 파일에 없음)

## 검수 포인트
1. 모든 수치는 2024 Median Pay / 2024–34 projections (OOH 최신판, Last modified 2025-08-28 기준) — 연 1회 갱신 대상
2. 감소 전망(-3% 정치학자, -2% 고교 교사, -4% 기자)도 미화 없이 그대로 표기 — 과장 금지 원칙 준수
3. Financial Analysts 페이지 본문에는 세부 직군별 중간값($101,350 / $106,000)이 따로 있으나, 헤드라인 Quick Facts 값($101,910)을 사용함
