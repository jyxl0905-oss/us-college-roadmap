# 평가 요소 비중(CDS C7) 4단계 전체 + 시험 제출 정책 재확인 — 검토 문서

- 조사일: 2026-09-27
- 출처: 평가 요소 비중은 각 대학 공식 Common Data Set C7 표, 시험 정책은 각 대학 입학처 공식 페이지
- 4단계: 매우 중요 / 중요 / 고려 / 반영 안 함. 학교가 비워 둔 칸은 표시하지 않아요.
- 인종 항목은 2024-25년부터 CDS 양식에서 빠져서 대부분 학교에 없어요.

## 0. 반영 내역 (2026-09-27 사용자 승인 — 전부 반영)

1. **University of Washington 시험 정책**: 공식 표기대로 "미반영"에서 "선택 제출"로 바꿨어요. 학교 상세에는 "대부분 지원자는 심사자가 점수를 보지 않음"이라는 설명을 붙였어요.
2. **Rutgers–Newark 시험 정책**: "선택 제출"에서 "미반영"으로 바꿨어요. 7년제 BA/MD 과정만 필수라는 설명을 붙였어요.
3. **"이 학교가 공식적으로 보는 것" 문구**
   - UConn: 끝 문장을 한국어·영어 모두 2025-26 CDS 기준으로 고쳤어요.
   - Syracuse: "(CDS는 공개하지 않음)"을 지웠어요.
4. **지원 보드 할 일 문구**: 134곳의 "매우 중요" 목록과 출처를 새 자료로 맞췄어요.
   - Clemson은 이번에 공식 PDF가 봇 차단에 막혀서, 8월 자료를 그대로 뒀어요.
5. **시험 요건 예외 설명 7곳**: 학교 상세의 시험 점수 줄에 공식 출처와 함께 붙였어요.
   - Harvard·Yale·Dartmouth·CMU·UW·Miami·Rutgers–Newark
6. **예전 연도 자료를 쓰는 학교**: 화면에 공시 연도가 함께 표시돼요.
   - 2023-24: Rutgers 3개 캠퍼스, Holy Cross, Yeshiva
   - 2022-23: Colorado School of Mines
