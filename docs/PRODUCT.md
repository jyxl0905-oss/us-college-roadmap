# 미국 대입 로드맵 — 서비스 소개

**주소**: https://uscollegeroadmap.com (모바일·PC 모두 지원)

한국 국제학교 학생(9~12학년)을 위한 미국 대학 입시 관리 툴입니다.
전담 카운슬러가 없어도, 학년·전공·목표 학교에 맞는 시즌별 체크리스트와 리포트를 받아
4년간 입시 준비를 스스로 관리할 수 있습니다. 챗봇/AI 없이 전부 검증된 데이터 기반으로 동작합니다.

---

## 1. 어떻게 쓰나요 (사용 흐름)

1. **온보딩 (2분)** — 한 화면에 한 질문씩 12개 답변
   - 졸업연도(학년 자동 계산) · 지원 신분(국제학생 여부) · 카운슬러 유무 · 학교 국제 인증
   - 문과/이과 선택 → 해당 계열 전공만 골라서 선택 (미정이면 건너뜀)
   - 목표 학교(톱 60 검색·복수 선택 / 순위대만 / 미정) · GPA · 수학 과목 · SAT · AP 개수 · TOEFL · 활동 자가진단
2. **리포트 프리뷰** — 6축 차트와 체크리스트 일부를 먼저 보여주고, 나머지는 블러 처리
3. **이메일 로그인** — 비밀번호 없이 메일 링크 클릭 한 번으로 가입·로그인 (매직 링크)
4. **전체 리포트 + 체크리스트** — 시즌 내내 돌아와서 항목을 체크하며 관리
5. **시즌 체크인** — 새 시즌(Fall/Spring/Summer)에 접속하면 3단계 확인 후 새 리포트 발급

## 2. 리포트에 나오는 것

| 항목 | 내용 |
|---|---|
| AO 박스 | "입학사정관이 지금 학년에서 보는 것" 3줄 요약 (학년별로 다름) |
| 6축 밸런스 차트 | 학업 강도·시험·대표 활동·리더십·교외 인정·스토리 점수를 레이더 차트로 |
| 약한 축 진단 | 가장 약한 축에 대해 학년×수준별 맞춤 처방 한 줄 |
| 어필 전략 | 가장 강한 축을 원서의 중심축으로 쓰는 법 한 줄 |
| 시즌 진행률 | 완료율 바 + 지난 시즌 대비 비교 (두 번째 시즌부터) |
| 목표 학교 카드 | 학교별 SAT 중간 50% 위 내 위치 마커, 시험 정책(필수/선택/미반영), 국제학생 합격률, Need-blind 여부, 전공 직접 선발(direct-admit) 경고, 학교가 공식적으로 밝힌 인재상 |
| 시즌 체크리스트 | 내 학년·시즌·전공·목표·신분 조건에 맞는 항목만 필터되어 표시. 항목마다 "왜 해야 하는지" 한 줄과 축 태그, 편집 가이드는 "가이드" 라벨 구분 |
| 국제학생 섹션 | 국제학생만 해당하는 항목(TOEFL, 재정 서류, I-20 등) 별도 표시 |
| 내보내기 | PDF 저장(인쇄), Word(docx) 다운로드 |
| 입시 기본기·용어집 | 입시 기본 개념 5가지 + 용어 30개 사전 |

## 3. 시즌 체크인 (재방문 시)

새 시즌에 접속하면:
1. 지난 시즌 미완료 항목 → 항목별 [이번 시즌으로 이월] / [건너뛰기]
2. 변경사항 입력 — 새 시험 점수 / 새 수상·활동 / GPA 변동 / 변동 없음(원탭)
3. 전공·목표 학교 유지 확인 → 새 시즌 리포트 발급

매년 8월 1일 학년이 올라가면 확인 팝업이 뜹니다.

## 4. 들어 있는 데이터 (전부 공식 출처)

- **학교 63개교** — US News 2026년판 1~59위 전체. SAT 범위·시험 정책·합격률 등은 각 대학의
  최신 Common Data Set과 공식 입학처 페이지에서만 수집 (추정치 0건, 확인 불가 값은 "미공개" 표시)
- **체크리스트 123개** — 전 학년×시즌 공통 백본 51개 + 전공별(CS·공학·비즈니스·수학·자연과학·
  프리메드·사회과학·인문·예술·미정) 오버레이 72개
- **처방 47개 + 어필 전략 7개** — 축×수준×학년 조합별 맞춤 문구
- **용어집 30개 + 입시 기본기 5꼭지**

원칙: 공식 데이터(수치·정책)와 편집 가이드(조언)를 명확히 구분하고, 합격 확률 예측("이 정도면 붙는다")은 하지 않습니다.
