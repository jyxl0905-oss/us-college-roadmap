# 지원 방식 가이드 (/guide/apply) — 검토용

작성 2026-11-21 · 상태: **사용자 승인 대기**

## 위치
- 왼쪽 메뉴 "학교·일정" 묶음 맨 위 "지원 방식 가이드" (폰: 더보기 → 학교·일정)
- 로그인 없이도 열람 가능, 로그인 시 내 목표 학교·프로필 반영

## 구성
1. **한눈에 비교 표:** ED·ED2·EA·REA/SCEA·RD·Rolling — 구속력, 다른 학교 조기 지원, 보통 마감·발표
2. **제도별 설명 (접기/펼치기):** 쉬운 말 설명 + 주의점 + "이 사이트 데이터 기준 해당 학교 수"
   - REA/SCEA 학교별 허용 범위 표: Harvard·Yale·Princeton·Stanford·Notre Dame·Georgetown
3. **1년 일정:** 11월 조기 마감부터 5월 1일 등록 결정까지
4. **조기 지원 결과 세 가지:** 합격·불합격·보류(defer)와 각각 할 일
5. **내 목표 학교의 지원 방식:** 목표 학교마다 ED/ED2/EA/REA/RD 가능 여부와 시기, 공식 마감 페이지 링크, 마감 캘린더로 연결
6. **ED를 어디에 쓸지 고민될 때:** 후보 최대 3곳 비교
   - 기본값: 내 목표 학교 중 ED·ED2가 있는 곳. 검색으로 추가할 수도 있음
   - 공식 수치: CDS ED 합격률, 전체·국제학생 합격률, SAT 중간 50%, 1년 총비용, 규모·위치
   - "나에게 맞는 점 / 고려할 점"은 아래 규칙으로만 만듦. **합격 가능성 예측 없음**
   - 마지막에 "ED 결정 전 스스로 확인할 것" 3가지

## "맞는 점 / 고려할 점" 규칙
| 조건 | 표시 |
|---|---|
| ED와 ED2 모두 있음 | ✅ ED2로 쓰는 선택지도 있음 |
| ED만 있고 ED2 없음 | ⚠️ 구속력 있는 조기 지원은 ED1뿐 |
| 국제학생 + need-blind + 전액 지원 | ✅ |
| 국제학생 + 전액 지원(need-aware) | ✅ |
| 국제학생 + need-blind 아님 | ⚠️ 비용과 ED 약속을 함께 따지기 |
| 공식 1년 총비용 있음 | ⚠️ ED는 구속력이 있으니 비용 먼저 확인 |
| 내 SAT 구간 분류 (기존 리포트와 같은 참고용 산식) | Reach면 ⚠️, 그 외 ✅ |
| SAT 계획 없음 + 시험 점수 필수 학교 | ⚠️ |
| 희망 전공이 direct admit 전공 | ⚠️ 학과 경쟁을 따로 봄 |
| 관심 표현(demonstrated interest) 반영 공시 | ✅ |
| CDS C7 "매우 중요" 요소 | ✅ 목록으로 표시 |

## 출처 (2026-11-21 확인)
- Common App Application Dictionary (2026-09): ED·EA·RD·롤링 정의
- Common App Early Decision Agreement (2026): 세 명 서명, 철회 의무, 재정지원 통지 전 철회 불필요
- NACAC Guide to Ethical Practice (2026-08): ED 중복 금지, 재정지원 부족 시 해제, REA가 RD·롤링을 막지 않음, 5월 1일
- College Board BigFuture: ED I/II 같은 규칙, 여러 학교 EA 가능, 결과 세 가지
- 각 대학 공식 페이지
  - Harvard·Yale·Princeton·Stanford·Notre Dame·Georgetown: REA 규칙
  - Tufts·WashU: ED2 예시, 보류 시 구속력 해제
  - Dartmouth: 재정지원 해제
  - Northwestern: 국제학생 need-aware
  - Carleton: 국제학생 장학 지원자에게 RD 권장
- 마감 분포("대부분 11월 초~중순" 등): 이 사이트 학교 데이터 집계
  - ED: 11월 초 91곳 / 중순 33곳
  - EA: 11월 초 113곳 / 중순 41곳
  - ED2: 1월 초 52곳 / 중순 31곳
  - RD: 1월 초·중순 143곳, 2월 초 58곳

## 확인 못 한 것 (넣지 않음)
- Princeton 페이지에 SCEA와 ED2를 같이 쓸 수 있는지는 적혀 있지 않음
- "College Decision Day"라는 표현의 공식 출처 없음 → "National Candidates Reply Date"로만 표기
- Wesleyan 국제학생 ED 안내는 페이지가 사라져서 제외
