# 전공별 9~12학년 로드맵 (툴 시드 콘텐츠 v2)

*읽는 법: 전공마다 표 하나. 각 학년에 **학업 트랙**(과목·AP·시험)과 **활동 트랙**(스파이크·외부 검증)을 나란히 배치. 공통 백본(GPA 관리, PSAT/SAT 일정, 에세이·원서 등 모든 전공 공통 항목)은 별도 문서이므로 여기엔 전공 고유 내용만 적음 — 실제 툴에서는 공통 백본 + 아래 오버레이가 합쳐져 학생에게 보임*

*학년 공통 대원칙: 9학년 = 기반·탐색 / 10학년 = 방향 확정·첫 검증 / 11학년 = 최대 하중·수확 / 12학년 = 마무리·증명*

## 변환 메모 (개발용)

- 각 셀이 체크리스트 항목 1~3개의 소스. 시즌 분배 원칙: 신청·확정류 → Spring(다음 학년 준비), 응시·출품류 → 해당 대회 시즌, 프로젝트 착수류 → Summer
- "미정" 11학년부터는 선택한 전공 표로 리다이렉트 — DB에서는 미정 전용 항목을 9~10학년에만 두면 됨
- 모든 대회 고유명사는 시즌 태그와 함께 저장 (예: AMC=가을, AIME=봄, Scholastic=가을 마감)
- 각 항목엔 v1 문서의 "왜+어떻게" 한 줄과 함정 경고를 붙여서 완성
