# F5. 가상 Common App ("내 원서") — 설계안 v1

작성 2026-08-10. 사용자 방향 확정 사항: 9학년부터 노출 / 리포트 옆 "추천" 배너 진입 / 짧은 작성 가이드 포함 / "다시 보지 않기".
아래 ✍️ 표시는 편집 판단이 들어가는 부분 — 사용자 승인 후 시드·구현.

## 0. 원칙
- 실제 Common App의 **구조·칸 이름·글자 수 제한은 그대로** 따르되, 디자인·문구는 우리 것. 화면 어디에서나 "가상 원서 — 실제 제출 아님" 명시.
- 학생 본인이 입력한 사실만 저장. 툴이 활동·에세이 내용을 만들거나 추천하지 않음 (라운드 추천·활동 선호 창작 금지 원칙 유지).
- 리포트는 "이 원서를 읽고 진단하는 화면", 원서는 "내가 채우는 화면"으로 역할 분리.

## 1. 진입·노출
- 리포트 상단(프로필 헤더 아래)에 **추천 배너**:
  - 제목: "🎓 가상 Common App으로 더 전략적으로 준비하기"
  - 본문 1줄: "실제 원서 형식 그대로 4년 동안 미리 채워요 — 활동·점수·지원 학교가 한 곳에"
  - 버튼: [내 원서 열기] / 링크: [다시 보지 않기] → localStorage `hide_commonapp_banner_{userId}`
  - 배너를 숨겨도 리포트 하단 버튼 목록(지원 보드·마감 캘린더 자리)에 **[📋 내 원서]** 는 항상 남음
- 노출: **9학년부터 전 학년**. 지원 학교 탭도 9학년부터 열되, 상단에 "지원 라운드·목표는 매년 바뀔 수 있어요 — 지금은 미리 그려보는 단계" 안내(11학년 여름 전).
- URL: `/app` (내 원서 홈), `/app/activities`, `/app/testing`, `/app/education`, `/app/colleges`, `/app/writing`

## 2. 탭 구성 (실제 Common App 섹션 대응)

### 2-A. 활동 (Activities) — 최대 10칸
필드 (실제 제한값): 활동 유형(선택지: 학술/예술/운동/봉사/직업/리서치/동아리/기타), 직책·리더십(50자), 단체명(100자), 설명(150자), 참여 학년(9/10/11/12 다중), 시기(학기 중/방학/연중), 주당 시간, 연간 주 수, 대학에서도 계속할 의향(예/아니오).
- 순서 드래그(모바일은 ▲▼)로 우선순위 — 실제 원서도 순서가 중요함을 툴팁으로 안내
- 글자 수 카운터 실시간, 초과 시 빨간색
- 카드 하단 [원서용 복사] → 3줄 형식(직책 / 단체 / 설명) 클립보드

### 2-B. 수상 (Honors) — 최대 5칸
제목(100자), 학년, 인정 범위(교내/지역·주/전국/국제) — 이 4단계가 실제 Common App 선택지.

### 2-C. 시험 (Testing)
- SAT: 응시일, 총점, 영어/수학 → 최고 점수 자동 계산(superscore 아님, 회차별 최고 총점)
- TOEFL/IELTS: 응시일, 총점(+영역)
- AP: 과목, 응시 연도, 점수(1~5)
- 프로필의 sat_band·toefl_status·ap_completed는 **여기 기록에서 자동 파생**(기록이 있으면 기록 우선, 없으면 기존 밴드 유지)

### 2-D. 학업 (Education)
- 현재 프로필 값(GPA 밴드·수학 트랙·AP 수강 중)을 이 탭에서 편집 — 기존 체크인 "변경사항" 화면과 중복되지 않게, 체크인은 이 탭으로 링크
- 수강 과목 목록(학년별, 과목명·수준 Honors/AP/IB) — 선택 입력. rigor 축은 기존 규칙 유지(과목 목록은 참고 표시만, 점수 반영 ✍️는 v2)

### 2-E. 지원 학교 (My Colleges) — 기존 /board 흡수
- 메인을 **라운드 칸** 레이아웃으로 개편: ED I / REA / EA / ED II / RD / 미배정
  - 칸 규칙 표시: ED I·REA는 1곳, REA 선택 시 타 사립 조기 칸에 경고, 국제학생+ED 재정지원 문구 (기존 경고 3종 그대로)
  - 칸 헤더에 마감 시기 라벨(F3 데이터), 학교 카드에 로고·상태 뱃지·완료율
  - 학교 이동: 카드 탭 → 라운드 선택 시트(그 학교 제공 라운드만)
- 카드 상세 = 기존 보드 상세(맞춤 준비·자동+커스텀 체크리스트·상태) 그대로 + **내 원서 연동 블록**: "내 SAT 최고점 vs 이 학교 중간50%", "내 활동 N개 중 이 학교 CDS Very Important 요소(에세이·인성 등)와 만나는 항목" — 사실 배치만, 판단 문구 없음
- 학생 입력 마감일(선택): "공식 페이지에서 확인한 날짜"를 직접 입력하면 D-day 표시. 툴은 날짜를 제공하지 않음.
- 기존 `/board`는 `/app/colleges`로 리다이렉트

### 2-F. 에세이 (Writing)
- Personal Essay: 주제 메모, 상태(미시작/브레인스토밍/초안/퇴고/완료), 단어 수 카운터(650 기준) — 본문 저장 여부 ✍️(개인정보 부담 vs 편의; 초안은 "메모만 저장, 본문은 저장 안 함" 제안)
- 학교별 보충 에세이: 학교 선택 → 문항 텍스트(학생이 공식 페이지에서 붙여넣기) + 상태 + 글자/단어 제한(학생 입력). 기존 커스텀 항목과 통합.

## 3. 내 원서 홈 (`/app`)
- 상단: "가상 원서 — 실제 제출 아님" 배지, 학년·시즌
- 섹션 카드 5개(활동 N/10 · 수상 N/5 · 시험 기록 N건 · 학업 · 지원 학교 N곳/라운드 배정 M곳 · 에세이 상태) — 각각 채움 정도 미니 바
- **작성 가이드(짧게)** ✍️ 초안 — 사실 기반, 실제 Common App 안내 기준으로 시드 전 확인:
  1. 활동은 최대 10개, 중요한 순서대로 — 위에서부터 읽힘
  2. 설명 150자: 무엇을·어떻게·결과가 뭐였는지, 숫자가 있으면 숫자로
  3. 수상은 최대 5개, 인정 범위(교내→국제)를 정확히
  4. 시험 점수는 학교마다 제출 정책이 다름 — 리포트의 시험 정책 칩 확인
  5. 지원 라운드는 ED 1곳·REA 규칙을 지키고, 마감은 반드시 공식 페이지에서 최종 확인
  6. 에세이는 원서 시즌 전에 초안 — 12학년 가을은 시간이 없음
  - 가이드 카드에도 [접기] (배너와 별개로 항상 접근 가능)

## 4. DB
- `activities`(id, user_id, sort_order, category, position(50), organization(100), description(150), grades int[], timing, hours_per_week, weeks_per_year, continue_in_college bool, updated_at)
- `honors`(id, user_id, sort_order, title(100), grade, level('school'|'regional'|'national'|'international'))
- `test_scores`(id, user_id, kind('sat'|'toefl'|'ielts'|'ap'), taken_on date, total int, section_scores jsonb, subject text)
- `courses`(id, user_id, grade, name, level('regular'|'honors'|'ap'|'ib'))
- `essays`(id, user_id, school_id nullable(개인 에세이면 null), prompt text, status, word_limit int, notes text, updated_at)
- `applications` 기존 유지 + `student_deadline date null` 추가
- 전부 RLS 본인만. profiles에 `commonapp_banner_hidden` 대신 localStorage(기기별) — 사용자 확정 "다시 보지 않기"는 가벼운 UX라 localStorage로 충분

## 5. 리포트 연동 규칙 ✍️ (초안 — 승인 필요)
현재: spike/leadership/validation = 온보딩 3단계 자가진단 + 해당 축 체크리스트 완료 가산.
제안: **기록이 있으면 기록이 자가진단을 대체**, 없으면 기존 방식 유지.
- spike(대표 활동): 활동 중 참여 학년 2년 이상 & 주 5시간 이상인 활동 1개당 +25 (상한 75) + 그 활동에 연결된 수상 있으면 +25 → 최대 100
- leadership: 직책 필드에 리더십 키워드(회장/부장/창립/캡틴/편집장/founder/president/captain/lead 등 ✍️목록 승인) 있는 활동 1개당 +35 (상한 70) + 2년 이상 지속 시 +30
- validation(교외 인정): 수상 최고 레벨 — 교내 30 / 지역·주 60 / 전국 85 / 국제 100, 2개 이상이면 +10(상한 100)
- testing: SAT 최고 총점이 있으면 밴드 자동 산출(1500+/1400-1490/1300-1390/미만) → 기존 계산 그대로
- 리포트 6축 카드에 "기록 기반" 배지 + "자가진단 대신 내 원서 기록으로 계산됨" 툴팁

## 6. 하지 않는 것
- 활동/에세이 내용 추천·자동 생성, 라운드 추천, 합격 가능성 표현
- 학교별 에세이 문항 시드(매년 변동, 학생 입력)
- 실제 Common App 제출·연동

## 7. 구현 순서 (각 단계 커밋·확인)
1. DB 마이그레이션 + 스키마 파일 + 내 원서 홈/배너/가이드(PLACEHOLDER 없이 승인 문구) 
2. 활동·수상 탭 (+원서용 복사)
3. 시험·학업 탭 + 프로필 파생 연동
4. 지원 학교 탭 = 보드 라운드 칸 개편 + 내 원서 연동 블록 + 학생 입력 D-day
5. 에세이 탭
6. 리포트 연동(§5 규칙) + 성장 그래프는 별도 후속
